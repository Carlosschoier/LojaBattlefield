# Battlefield Store

Sistema desktop para gerenciamento de uma loja de produtos
relacionados à temática Battlefield.

## 📌 Status do Projeto

**Em desenvolvimento**

## 🛠️ Tecnologias

- Java
- Java Swing
- JDBC
- MySQL

## 👨‍💻 Equipe de Desenvolvimento

- Carlos Eduardo Schoier

## 🎯 Objetivo do Software

O Battlefield Store tem como objetivo auxiliar no gerenciamento
das atividades de uma loja, permitindo o controle das principais
informações utilizadas no sistema por meio de uma aplicação
desktop desenvolvida em Java.

Os dados são armazenados e consultados utilizando um banco de
dados MySQL por meio da tecnologia JDBC.

## ⚙️ Funcionalidades do Sistema

- Sistema de login;
- Cadastro de produtos;
- Gerenciamento de produtos;
- Cadastro de clientes;
- Gerenciamento de clientes;
- Cadastro de fornecedores;
- Gerenciamento de fornecedores;
- Gerenciamento de pedidos;
- Operações de caixa;
- Consulta, alteração e exclusão de registros;
- Persistência dos dados em banco de dados MySQL.
